# PROJECT: Cortexium 2.0

## Vision
Cortexium 2.0 is an **ambient intelligence platform** that transforms the first-person camera feed (POV) of a user into a continuous stream of structured knowledge — then acts on that knowledge in real time through adaptive XR overlays, an agentic AI orchestration layer, and persistent memory.

## Core Motto
**Adaptive Learning at Its Finest**

## Technical Constraints
- **Primary Stack**: Python (FastAPI), React (WebXR/Three.js), React Native (Mobile), Unity (Optional High-Fidelity).
- **Inference**: On-device processing preferred (Privacy-by-Design).
- **Database**: Supabase (PostgreSQL) for relational state; Redis for pub/sub.
- **AI**: YOLOv8 (Object Detection), DeepFace (Face Recognition), Local LLM (Ollama/Transformers).
- **Communication**: Real-time WebSockets for event bus.

## Design Aesthetics
- Vibrant colors, dark mode, glassmorphism, dynamic animations.
- Modern typography (Inter/Outfit).
- Micro-animations and interactive hover effects.
