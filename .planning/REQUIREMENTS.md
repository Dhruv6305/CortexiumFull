# REQUIREMENTS: Cortexium 2.0

## V1: Core Ambient Intelligence (Current Focus)
- [ ] **Input Layer**: POV camera feed, microphone, GPS, and sensor aggregation.
- [ ] **CV Engine**: Real-time activity classification, face recognition (DeepFace), and object detection (YOLOv8).
- [ ] **Agentic AI**: 5 core agents (Router, Navigation, Social, Environment, Memory).
- [ ] **Backend**: FastAPI with WebSocket hub and Supabase integration.
- [ ] **WebXR Frontend**: Dashboard with AR overlays and persistence logging.
- [ ] **Offline Mode**: Support for video training/replays as alternative to live feed.

## V2: Enhanced Immersive Experience
- [ ] **Adaptive Learning**: Predictive persona modeling and proactive alerts.
- [ ] **React Native Mobile**: Native iOS/Android apps with AR support.
- [ ] **Unity XR Bridge**: High-fidelity XR training and immersive playback.
- [ ] **Encounter Graph**: Complex social mapping and historical prompts.
- [ ] **Explainability**: YAML-based rule descriptions for all agent actions.
